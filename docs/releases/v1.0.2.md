# Min Tracker 1.0.2

- Glömt lösenord direkt från inloggningsskärmen, med förifylld e-postadress och återställningsmejl via Supabase.
- Välj och bekräfta nytt lösenord i appen när återställningslänken öppnas.
- Frivillig snabb inloggning med fingeravtryck eller säker ansiktsigenkänning, via Androids biometriska dialog.
- Ny inställning under Profil → Inställningar → Säkerhet för att aktivera eller stänga av biometri.
- Krypterad sessionslagring i Android Keystore, kontroll av sessionen mot servern och rensning vid utloggning.
- Befintligt uppdateringssystem via GitHub Releases; uppdateringen är frivillig.

Installera `MinTracker-v1.0.2.apk` över din befintliga installation. APK:n behåller samma signatur som tidigare leveranser. Avinstallera inte appen för att uppdatera, eftersom det kan ta bort lokala pass.

VersionCode: 3. Minsta kompatibla Androidversion: Android 8.0. Stark registrerad biometri behövs för snabb inloggning; e-post och lösenord fungerar som vanligt.

Verifiering: 74 JVM-tester godkända, APK och instrumenteringstester byggda, Android Lint utan fel. Ingen Android-enhet var ansluten: faktisk biometrisk dialog, mejllänk, lösenordsbyte och installation över tidigare APK behöver fortfarande verifieras på telefon.
